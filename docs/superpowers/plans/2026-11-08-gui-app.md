# GUI App (Phase 2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop window, `zrush-gui`, that shows several repos in tabs — worktrees and their sessions on the left, the selected conversation on the right — opens the IDE or the agent in a new terminal, asks the misfiled/orphan questions, edits the settings, and wears themes loaded from files.

**Architecture:** New crate `crates/zrush-gui` (binary `zrush-gui`) depending on `zrush-core` only. Each tab owns one repo's `Zrush`, `Loader` and `RepoSnapshot` (all from Phase 1) in a `Tab` model that has no egui in it and is tested headless; thin egui views draw it. Packaging, `gui-v*` releases and self-update are Phase 2b (separate plan).

**Tech Stack:** Rust 2024, eframe/egui 0.36.2 (with `persistence`), egui_dock 0.21.1, egui_commonmark 0.25.0, rfd 0.18 (folder picker), egui_kittest 0.36.2 (UI tests).

**Spec:** `docs/superpowers/specs/2026-11-08-zrush-gui-design.md` (Goals, Non-goals, Phase 2, Look). Throwaway reference: branch `spike/egui-gui`.

## Global Constraints

- `zrush-gui` depends on `zrush-core` only, never on the `zrush` (TUI) crate. Anything that decides goes in core.
- Workspace rules apply: `[lints] workspace = true`, `unsafe_code = "forbid"`, clippy pedantic `-D warnings`, no `unwrap`/`expect` outside tests (`main` included: show the error, do not panic), MSRV `1.99`, deps declared in `[workspace.dependencies]`.
- `cargo deny check` must pass. If egui's bundled fonts bring licences `deny.toml` lacks (e.g. `OFL-1.1`, `Ubuntu-font-1.0`), add exactly those, each with a one-line comment naming the crate, as the file already does.
- egui 0.36 API (learned in the spike): `egui::Panel::left(id).resizable(true).default_size(px).show(ui, …)`, `egui::Panel::top(id)`, `CentralPanel::default().show(ui, …)`; `eframe::App` implements `fn ui(&mut self, ui: &mut egui::Ui, frame: &mut eframe::Frame)`; `egui_dock::TabViewer` requires `fn id(&mut self, tab) -> egui::Id`.
- The GUI never writes a GUI-only override into `config.toml`: whole-conversation reads use `Zrush::keep_override(|c| c.preview_turns = usize::MAX)`.
- Labels a user sees for questions, choices and action results are core's strings (`zrush_core::intent`, `zrush_core::actions`), never retyped.
- No status glyphs (●, ◌) in text: live/resumable are painted circles, so no extra font is needed (ruling on the spec's "bundled font": the GUI draws no such glyph).
- Done for each task = `./check` prints `all green`.

## Review Focus

1. A repo saved in `gui_repos` was deleted or moved since the last launch: its tab shows the error and the other tabs load; closing it drops it from `gui_repos` — Task 4.
2. A tab is closed while its probes are still running: nothing panics and the workers stop — Tasks 1 and 3.
3. The same repo added twice (by path or through another of its worktrees): no second tab; the existing one is focused — Task 4.
4. A setting changed in the settings window applies to every open tab, and a refused value shows its error without writing anything — Task 7.
5. An action git refuses (removing a dirty worktree, an invalid branch name when recreating an orphan's worktree) shows the error in the tab and the window keeps working — Task 6.

### Task 3: The crate and the `Tab` model

**Files:**
- Create: `crates/zrush-gui/Cargo.toml`, `crates/zrush-gui/src/main.rs` (stub window), `crates/zrush-gui/src/lib.rs`, `crates/zrush-gui/src/tab.rs`, `crates/zrush-gui/src/testing.rs` (`#[cfg(test)]` scratch repo, as `crates/zrush-core/src/testing.rs`)

**Interfaces:**
- Consumes: `zrush_core::{app::Zrush, loader::{Loader, Sink, Event, PreviewJob, Preview}, snapshot::{RepoSnapshot, TreeView, Applied}, host::Host}`.
- Produces, in `zrush_gui::tab`:
  - `pub type Wake = Arc<dyn Fn() + Send + Sync>` — called after every loader event (the app passes `ctx.request_repaint`).
  - `pub struct Tab { pub repo: PathBuf, pub title: String, pub snap: RepoSnapshot, pub view: TreeView, pub selected: Option<String> /* preview key */, pub error: Option<String>, pub flash: Option<String>, pub busy: Option<String>, … }`
  - `Tab::open(repo: &Path, dirs: &Dirs, cfg: &Config, host: Box<dyn Host>, wake: Wake) -> Tab` — never fails: a repo that cannot be opened gives a tab with `error = Some(..)`, `title` = the path's last component. On success: `keep_override(|c| c.preview_turns = usize::MAX)`, first `refresh()`.
  - `Tab::main_root(&self) -> Option<&Path>` (`None` for a broken tab).
  - `Tab::poll(&mut self) -> bool` — drains the channel into `snap.apply`; rebuilds the cached rows on `Applied::Rows`; `Acted` clears `busy`, sets `flash` or `error`, refreshes; returns whether anything changed.
  - `Tab::rows(&self) -> &[Row]`, `Tab::live_count(&self) -> usize`, `Tab::refresh(&mut self)`, `Tab::refresh_if_due(&mut self, now: Instant)` (every `REFRESH_EVERY = Duration::from_secs(10)`).
  - `Tab::select(&mut self, row: &Row)` — sets `selected`, asks `snap.want_preview` and the loader for it; `Tab::preview(&self) -> Preview`.
  - `Tab::zrush(&self) -> Option<&Arc<Zrush>>`.
